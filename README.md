About:
A Letterboxd-inspired movie logging web application where users can discover movies, log films they have watched, rate and review them, and maintain a personal watchlist. Movie data is sourced from the TMDB public API.

How to Run:
Run the development server:

1. Install dependencies: npm install
2. Run in one terminal: npm run dev
3. Run in another terminal: npm run client:dev 

Open http://localhost:5173 with your browser.
